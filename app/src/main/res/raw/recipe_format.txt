POURISTA RECIPE FORMAT

The file is plain JSON in UTF-8. It holds one object with the fields format,
version and a list of recipes. Export from the app produces the same file.

{
  "format": "pourista.recipes",
  "version": 1,
  "recipes": [ ... ]
}

RECIPE

  name       string, required. The name.
  brewer     string. Dripper or device: "Hario V60-02", "AeroPress".
  dose       number. Coffee dose, grams.
  water      number. Total water, grams. Left out — the sum of the pours
             from the steps is used.
  temp       integer. Water temperature, °C. Defaults to 94.
  grinder    string. Grinder.
  grind      string. Grind setting: "24 clicks", "6.5", "medium".
  bean       string. Coffee.
  roaster    string. Roaster.
  notes      string. Notes, several lines allowed.
  autoStart  true/false. Whether to start the timer by itself as soon as water
             shows up on the scale. True for pour-over, false for espresso.
  steps      list of steps, required.

STEP

  kind       kind of step, one of:
               BLOOM     bloom, always the first step of a recipe;
               POUR      an ordinary pour;
               WAIT      a pause with no water added;
               SWIRL     swirl the dripper;
               STIR      stir;
               DRAWDOWN  drawdown, always the last step of a recipe;
               PRESS     press the plunger (AeroPress).
             With the field left out, a step with water counts as POUR,
             a step without water as WAIT.
  duration   integer, seconds. Length of the whole step: the pour plus the
             pause after it. That is how recipes are written: "50 g, 45 seconds".
  water      number, grams. How much to add ON THIS step (not the running
             total). The app works out what the scale should read.
  flow       number, g/s. Pouring speed. The pour time comes from it: 50 g at
             5 g/s means 10 seconds of pouring and 35 seconds of pause inside
             a forty-five-second step. The speed is what gets stored: change
             the dose and the volume is recalculated, the comfortable speed stays.
  title      string. Your own name for the step, if you need one.
  note       string. A hint for the step.

RULES

  • There can be only one bloom, and only as the first step.
  • There can be only one drawdown, and only as the last step.
  • Steps run back to back, with no gaps in time: a step starts at the sum of
    the durations before it.
  • A pour must not outlast its step: water / flow ≤ duration.
  • The sum of water over all steps must match the recipe's water field.

EXAMPLE

{
  "format": "pourista.recipes",
  "version": 1,
  "recipes": [
    {
      "name": "V60 · James Hoffmann",
      "brewer": "Hario V60-02",
      "dose": 15,
      "water": 250,
      "temp": 95,
      "grind": "medium",
      "notes": "50 g bloom, two pours, a gentle swirl at the end.",
      "autoStart": true,
      "steps": [
        { "kind": "BLOOM",    "duration": 45, "water": 50,  "flow": 5 },
        { "kind": "POUR",     "duration": 30, "water": 100, "flow": 4.5 },
        { "kind": "POUR",     "duration": 30, "water": 100, "flow": 4.5 },
        { "kind": "SWIRL",    "duration": 10 },
        { "kind": "DRAWDOWN", "duration": 95 }
      ]
    }
  ]
}

WHAT TO ASK AN LLM

  "Write a V60 recipe for 18 g of coffee at a 1:16 ratio in this format.
  Return JSON only." — and paste the text above.

  The answer can be copied as is: in the recipe list pick "Import from the
  clipboard". The app strips ```json fences and any prose around the JSON
  by itself.
