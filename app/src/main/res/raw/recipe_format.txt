ФОРМАТ РЕЦЕПТОВ POURISTA

Файл — обычный JSON в кодировке UTF-8. В нём один объект с полями format,
version и списком recipes. Такой же файл создаёт экспорт из приложения.

{
  "format": "pourista.recipes",
  "version": 1,
  "recipes": [ ... ]
}

РЕЦЕПТ

  name       строка, обязательно. Название.
  brewer     строка. Воронка или прибор: «Hario V60-02», «AeroPress».
  dose       число. Доза кофе, граммы.
  water      число. Общий объём воды, граммы. Если не указать — возьмётся
             сумма проливов из шагов.
  temp       целое. Температура воды, °C. По умолчанию 94.
  grinder    строка. Кофемолка.
  grind      строка. Помол: «24 клика», «6.5», «средний».
  bean       строка. Кофе.
  roaster    строка. Обжарщик.
  notes      строка. Заметки, можно многострочные.
  autoStart  true/false. Пускать ли таймер автоматически, как только на весах
             появится вода. Для пуровера true, для эспрессо false.
  steps      список шагов, обязательно.

ШАГ

  kind       вид шага, одно из:
               BLOOM     блуминг, всегда первый шаг рецепта;
               POUR      обычный пролив;
               WAIT      пауза без долива;
               SWIRL     покачать воронку;
               STIR      размешать;
               DRAWDOWN  слив, всегда последний шаг рецепта;
               PRESS     отжим поршня (аэропресс).
             Если поле не указано, шаг с водой считается POUR, без воды — WAIT.
  duration   целое, секунды. Длительность всего шага: влив плюс пауза после
             него. Именно так рецепты и пишут: «50 г, 45 секунд».
  water      число, граммы. Сколько долить НА ЭТОМ шаге (не суммарно!).
             Приложение само посчитает, сколько должно быть на весах.
  flow       число, г/с. Скорость влива. Из неё считается время влива:
             50 г при 5 г/с — это 10 секунд влива и 35 секунд паузы внутри
             сорокапятисекундного шага. Хранится именно скорость: при смене
             дозы объём воды пересчитывается, а комфортная скорость остаётся.
  title      строка. Своё название шага, если нужно.
  note       строка. Подсказка к шагу.

ПРАВИЛА

  • Блуминг может быть только один и только первым шагом.
  • Слив может быть только один и только последним шагом.
  • Шаги идут подряд, без пропусков времени: время начала каждого шага —
    это сумма длительностей предыдущих.
  • Влив не должен быть длиннее шага: water / flow ≤ duration.
  • Сумма water по всем шагам должна совпадать с полем water рецепта.

ПРИМЕР

{
  "format": "pourista.recipes",
  "version": 1,
  "recipes": [
    {
      "name": "V60 · James Hoffmann",
      "brewer": "Hario V60-02",
      "dose": 15,
      "water": 250,
      "temp": 95,
      "grind": "средний",
      "notes": "Блум 50 г, два пролива, лёгкое покачивание в конце.",
      "autoStart": true,
      "steps": [
        { "kind": "BLOOM",    "duration": 45, "water": 50,  "flow": 5 },
        { "kind": "POUR",     "duration": 30, "water": 100, "flow": 4.5 },
        { "kind": "POUR",     "duration": 30, "water": 100, "flow": 4.5 },
        { "kind": "SWIRL",    "duration": 10 },
        { "kind": "DRAWDOWN", "duration": 95 }
      ]
    }
  ]
}

ЧТО СКАЗАТЬ НЕЙРОСЕТИ

  «Составь рецепт для V60 на 18 г кофе и пропорцию 1:16 в этом формате.
  Верни только JSON.» — и приложить текст выше.

  Готовый ответ можно просто скопировать и выбрать в списке рецептов
  «Импортировать из буфера обмена». Обрамление ```json и пояснения вокруг
  JSON приложение отбросит само.
