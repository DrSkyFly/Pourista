# Проверка DiFluid Microbalance Ti в Pourista

## Сборка и установка

Тестовая версия основана на Pourista 1.9.8. Вариант `githubDebug` имеет имя **Pourista Ti Test**, идентификатор `com.pourista.titest` и собственный файловый провайдер. Оригинальная Pourista использует `com.pourista`. Android хранит настройки, рецепты и историю этих пакетов раздельно.

1. На телефоне с Android 10 или новее откройте файл **Pourista-Ti-Test.apk**. Если Android запросит разрешение на установку, разрешите её для приложения, из которого открыли файл.
2. Откройте **Pourista Ti Test**, разрешите использование весов. Включите Bluetooth. При первом подключении выдайте разрешение на устройства поблизости, а на Android 10–11 — на местоположение. На этих версиях Android для поиска также может потребоваться включить геолокацию телефона.
3. Отключите весы в BeanConqueror и других приложениях, которые могли удерживать соединение. Включите Ti и нажмите значок Bluetooth на экране заваривания.

Для повторной сборки используйте JDK 21, Android SDK Platform 37.0 и Build Tools 36.0.0. В каталоге проекта выполните `gradlew.bat testGithubDebugUnitTest` и `gradlew.bat assembleGithubDebug`. В Windows для сборки удобен путь из латинских букв. APK появится в `app/build/outputs/apk/github/debug/`. Gradle подписывает его локальным отладочным ключом.

## Проверка на весах

| Действие | Что проверить |
|---|---|
| Открыть обе версии Pourista | На устройстве два отдельных приложения. Прежние заваривания видны в оригинальной версии. |
| Начать поиск с выключенными весами | Через 20 с поиск заканчивается. Повторное нажатие запускает новую попытку. |
| Включить Ti и подключиться | Весы распознаются. Соединение считается готовым после первого корректного пакета веса. На GATT и начало потока отведено 35 с с момента обнаружения. |
| Поставить предмет известной массы, нажать «Тара», снять его | Показания совпадают с дисплеем весов. После тары виден ноль, после снятия — отрицательный вес. В журнале можно сверить десятые доли грамма. |
| Включить автостарт по первой воде и автофиниш, начать заваривание | Первая вода запускает таймер. Во время влива меняются текущий вес, остаток до цели и скорость. Достижение цели или стабилизация рядом с ней завершает влив. |
| Завершить последний влив и снять чашку | При включённом автофинише заваривание завершается. Открыть запись в истории и проверить обе кривые, длительность и итоговый вес. |
| Выключить подключённые весы, включить снова | После потери связи приложение пытается подключиться повторно с паузой 10 с. Если попытка окончилась до включения весов, подключиться кнопкой Bluetooth и повторить тару. |
| Отключить весы из приложения | Новая попытка начинается по запросу пользователя. При отказе в системном разрешении поиск доступен после выдачи разрешения. |
| Посмотреть заряд | Если весы прислали ответ состояния, процент отображается в интерфейсе. |

## Журнал без компьютера

Откройте **Настройки → Журнал весов → Начать запись**. Запись можно начать до подключения. В этом случае включите весы и дождитесь обнаружения. При проверке тары поставьте груз, нажмите «Тара», подождите пару секунд и снимите груз. При сбое дождитесь окончания поиска или подключения. Нажмите **Остановить → Отправить** и выберите, куда сохранить или передать текстовый файл. Для разбора приложите журнал, версию Android и укажите, на каком шаге возник сбой.

В начале файла есть последние события соединения за текущий запуск приложения. Байты входящих уведомлений попадают в файл во время записи. В debug-сборке их также можно смотреть в Logcat по тегу `PouristaDiFluid`. Журнал показывает имя из объявления, UUID, идентификаторы производителей, выбранную модель, состояние GATT, свойства характеристик, подписку, команды, ответы и ошибки. При неожиданном разрыве библиотека BLESSED передаёт приложению состояние DISCONNECTED без низкоуровневого кода HCI.

## Основание для изменений и границы проверки

В исходной версии на имени `Mb Ti 123456` выбор драйвера возвращал `null`. Полное имя `Microbalance Ti` совпадало с общим правилом Microbalance и направляло приложение к сервису `00EE`. Поиск продолжался без предельного срока, а соединение могло показываться готовым до подписки.

У Ti сервис `00DD`, у обычной Microbalance — `00EE`. Обе модели используют `AA01` для открытого протокола. Приложение принимает UUID из рекламы или имя в объявлении/scan response, затем проверяет GATT. Подтверждённой сигнатуры manufacturer data для различения моделей в источниках нет. Идентификаторы выводятся в журнал. После подписки приложение запрашивает граммы при включённой настройке, включает автоматические показания и запрашивает заряд.

Тестовые примеры включают опубликованные кадры 394,0 г, 0,0 г и статуса с зарядом 63%. Для отрицательного веса и унций использованы отдельно обозначенные синтетические кадры. Единицы с кодами 0 и 1 переводятся в граммы. Неопределённая в документации единица `gering` и повреждённые кадры пропускаются. Таймер и расчёт скорости остаются в движке заваривания Pourista. Для открытого протокола производитель указывает минимальные версии прошивки V010 для Ti и V300 для обычной модели.

Успешная сборка, проверка подписи и модульные тесты подтверждены на компьютере. Владелец установил Pourista Ti Test на свой Android-телефон, проверил приложение с физическими DiFluid Microbalance Ti и подтвердил, что всё работает. Отдельные результаты по пунктам таблицы, модель телефона и версия прошивки весов не зафиксированы.

## Результаты и изменённые файлы

На Windows выполнены обе задачи Gradle, testGithubDebugUnitTest и assembleGithubDebug. Прошли все 167 тестов, без ошибок и пропусков. Из них 35 проверяют драйверы весов, включая 7 новых тестов DiFluid. В готовом APK проверены идентификатор пакета, файловый провайдер, название и минимальный API 29. Проверка apksigner подтвердила подпись APK Signature Scheme v2 сертификатом Android Debug. Проверка zipalign прошла.

Файлы относительно корня репозитория:

- app/build.gradle.kts — отдельный идентификатор githubDebug и отладочная подпись.
- app/src/githubDebug/AndroidManifest.xml — имя тестового приложения и исключение приёмника для постановочных скриншотов.
- app/src/main/java/com/pourista/scale/DifluidMicrobalanceDriver.kt — оба сервиса, разбор пакетов и команды.
- app/src/main/java/com/pourista/scale/ScaleDriver.kt — регистрация Ti и выбор модели по объявлению.
- app/src/main/java/com/pourista/scale/ScaleRepository.kt — сканирование, GATT, тайм-ауты, повторное подключение, диагностика и передача измерений.
- app/src/test/java/com/pourista/scale/DifluidMicrobalanceTest.kt — новые тесты обнаружения, пакетов, команд и скорости.
- app/src/test/java/com/pourista/scale/NewScaleDriversTest.kt — замена некорректного кадра старого теста официальным примером.
- docs/difluid-ti-test.md — инструкция и результаты.
